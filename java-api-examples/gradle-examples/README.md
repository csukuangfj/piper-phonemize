# piper-phonemize Gradle Example

This directory demonstrates how to use piper-phonemize via Gradle.

## Prerequisites

- JDK 8 or above
- Gradle 8.x (or use the included Gradle wrapper)

## Dependencies

The project uses [JitPack](https://jitpack.io/) to fetch piper-phonemize artifacts.

## Build

```bash
cd java-api-examples/gradle-examples
./gradlew build
```

## Run

```bash
./gradlew run
```
